# Vaibhav Wable — Portfolio

Personal portfolio for **Vaibhav Wable**, Software Engineer at CentraLogic (Pune), also open to freelance Flutter / React Native / web work.

**Live:** [wablevaibhav.github.io](https://wablevaibhav.github.io)

## Stack

- React 19 + Vite 8
- Tailwind CSS v4 (charcoal / steel / cyan design tokens)
- Framer Motion
- react-icons, react-type-animation, react-intersection-observer
- Typography: **Syne** (display) + **Sora** (body)

## Content

All copy and listings live in `src/data/portfolioData.js`:

- Personal info, resume, and social links
- Skills, experience (CentraLogic, freelance, RootKit), projects, education

## Run locally

```bash
git clone https://github.com/wablevaibhav/wablevaibhav.github.io.git
cd wablevaibhav.github.io
npm install
npm run dev
```

```bash
npm run build    # production build → dist/
npm run preview  # preview production build
```
